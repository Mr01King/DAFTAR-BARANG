STOCK BARANG - VERCEL + NEON

Aplikasi PWA inventaris apotek untuk dipakai bersama di 3 HP. Hosting di Vercel, database PostgreSQL Neon.

FITUR
- Login dengan username dan password masing-masing.
- Akun owner pertama dibuat otomatis saat login pertama.
- Owner dapat menambahkan akun admin dari menu Kelola admin.
- Admin dapat mengelola produk dan stok.
- Daftar barang habis, stok menipis, riwayat masuk/keluar.
- Sinkronisasi otomatis setiap 15 detik.

PERSIAPAN DEPLOY
1. Upload isi folder stock_barang_app ke repository GitHub.
2. Import repository ke Vercel.
3. Hubungkan database Neon dan pastikan DATABASE_URL tersedia di Project > Settings > Environment Variables.
4. Tambahkan environment variables berikut di Vercel (Production, Preview, Development):
   OWNER_NAME = Zane
   OWNER_PASSWORD = buat password baru yang kuat (minimal 10 karakter). Jangan gunakan password yang pernah dibagikan di chat.
   AUTH_SECRET = string acak panjang minimal 32 karakter.
   DATABASE_URL = otomatis dari integrasi Neon.
5. Di Neon SQL Editor, jalankan seluruh isi database.sql.
6. Redeploy project di Vercel.
7. Buka URL aplikasi. Login pertama dengan username sesuai OWNER_NAME dan password OWNER_PASSWORD. Akun owner akan dibuat otomatis.
8. Setelah masuk, buka Kelola admin > + Admin untuk membuat akun pegawai.
9. Di HP kedua dan ketiga, buka URL yang sama dan login menggunakan akun masing-masing.

CATATAN KEAMANAN
- Password owner dan AUTH_SECRET hanya disimpan di Vercel Environment Variables, jangan di file frontend atau GitHub.
- Owner bisa membuat akun admin. Admin tidak bisa membuat owner/admin lain.
- Gunakan password berbeda untuk setiap admin dan jangan membagikan akun owner.
- Bila mengubah OWNER_PASSWORD setelah akun owner pertama sudah dibuat, perubahan environment variable tidak otomatis mengubah password di database. Ubah password melalui prosedur reset database yang aman.
- Ini aplikasi inventaris, bukan sistem rekomendasi penggunaan obat.
